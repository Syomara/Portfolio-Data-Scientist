# Visualizaciones en Phyton

En esta carpeta se muestran visualizaciones realizadas en **Phyton** utilizando bases de datos tabulares, obteniendo conclusiones de estas visualizaciones que permiten obtener información clara sobre la base.

🎯 Objetivo

El proyecto busca encontrar patrones y similitudes de los datos que determinen una tendencia y puedan ser luego utilizados en Machine Learning, en este caso se realizan varios análisis gráficos para obtener información primaria que permita conocer y entender el comportamiento de los datos.
