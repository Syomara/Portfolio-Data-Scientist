# Análisis de datos no tabulares

En esta carpeta se muestra un análisis de datos no tabulares, se comienza con el procesamiento de los datos, el análisis de variables en forma de gráficos para evaluar comportamientos, se realiza una estandarización de las reseñas para lograr una base de datos más simple a la hora de implementar un modelo predictivo, se implementan 2 modelos predictivos distintos y se compara su desempeño mediante métricas destinadas a este fin.
