# Modelos de Machine Learning

En esta carpeta se muestra un proyecto donde se utiliza procesamiento de datos de una base de datos para luego aplicar un modelo de Machine Learning donde se pueda predecir resultados en base a ciertas variables, además de obtener los indicadores evaluadores del modelo.

  https://colab.research.google.com/drive/1fE57pVEJ_gFvpUVjzfXx4ISDlqigNu1y?authuser=1
- Link de carpeta donde se encuentra el Colab y la base de datos original:
  https://drive.google.com/drive/folders/11JhB0WWQK6AFOR3cmgBtAIT4D5DSJB0b?usp=drive_link

🎯 Objetivo

El objetivo del proyecto es evaluar en que lugar del Uruguay ocurren la mayor cantidad de delitos, además de evaluar si existe algún patrón en las victimas de estos delitos analizando los datos con correlaciones estadísticas además de gráficas descriptivas de los datos.
