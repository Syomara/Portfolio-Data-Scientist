# Proyecto de Práctica - Dataset Sample Superstore

🎯 Objetivo:
Este proyecto tiene como objetivo el análisis profundo de un dataset de ventas que se encuentra en Kaggle con tal de combinar el uso de SQL y Python en el mismo Dataset. 
Para esto se utiliza COLAB de Google donde se puede trabajar con códigos tanto de Phyton como con simulaciones de setencias de SQL. 

🔗 Contenido:
- Link de dataset original: https://www.kaggle.com/datasets/naveenkumar20bps1137/sample-superstore
- Link de proyecto en Colab: https://colab.research.google.com/drive/1Io0torfjiYG2yYHhvx1Q0veqzyeN4npe?usp=sharing
